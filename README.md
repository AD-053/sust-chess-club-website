# SUST Chess Club Website

A responsive website for the Shahjalal University of Science and Technology Chess Club. The website introduces the club, displays upcoming events, presents the development team, and helps students connect with the chess community.

## Features

- Responsive navigation bar
- Home page with hero section and club information
- Events, team, gallery, and contact sections
- About page describing the project and development team
- Shared responsive footer on every page
- Custom brown theme inspired by the club logo
- Responsive design for mobile, tablet, and desktop

## Technologies

- Next.js
- React
- Tailwind CSS
- DaisyUI
- React Icons

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
